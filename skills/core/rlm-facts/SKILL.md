# rlm-facts

RLM_FACTS_BODY

Query the facts, knowledge, and observations the runtime exposes to you before guessing. Keep retrieved evidence distinct from your own inference. Derive results deterministically with the runtime's Prolog operations when they fit, and use model judgment only for the uncertainty that remains.
