- Compatibility :: Named dict tags and the named default =conversation_metadata{}= remain unchanged.
- Verification :: Cover nested anonymous metadata through list/reopen, named-tag preservation, variable/cycle rejection without partial creation, and persistent close/reopen.

** Adversarial review
- Nested anonymous tags could remain non-ground if only the outer tag were rewritten; require the shared recursive normalizer and assert both levels.

- Catching every exception would hide programming/backend faults; catch only =rlm_closed_data_fault/1=.
- A rejected value could partially reserve its id if validation occurred after dispatch; assert the id can be created successfully after rejection.
- Replacing all dict tags would destroy named-tag semantics; assert a named metadata tag survives unchanged.
- No new callable execution is introduced: normalized metadata remains inert data and is never invoked.
