* Analyze
The compiler already emits all data needed for the first runtime command: normalized text, closed target, KB provenance, and a SHA-256 fingerprint over the canonical command payload. No new selector, scheduler, authority system, or subagent runtime is required.

The execution boundary therefore has two independent checks:
1. command integrity/allow-listing, owned by =rlm_prompt_command=;
2. execution permission/effect/limits, owned by =rlm_tool= and the registered canonical tool handler.

A valid compiler fingerprint proves only that the closed command payload has not been changed. It is not execution authority. A fingerprint-valid command still requires the caller's normal tool capability and whatever authority/effect policy the canonical tool runtime requires.

* Design
Add =prompt_command_execute/6= to =rlm_prompt_command=.

For the current closed vocabulary:
- accept only ground =prompt_command{...}= data;
- accept only the current compiled target =tool(rlm_subagent)=;
- remove =fingerprint= and recompute the canonical compiler fingerprint over the remaining payload;
- reject target substitution before dispatch;
- reject payload tampering when the fingerprint no longer matches;
- derive the closed typed invocation =json{query:Command.text}=;
- delegate execution unchanged to =rlm_tool:tool_invoke/7=.

Pre-dispatch rejection returns a small =prompt_command_trace= with =status:command_rejected=. Successfully admitted commands return the canonical tool trace unchanged.

* Adversarial review
- Do not meta-call =Command.command= or any model/KB term.
- Do not make =tool(Name)= a generic executable KB vocabulary. The first adapter remains exactly =rlm_subagent=.
- Check target substitution even though it also invalidates the fingerprint, so an unsupported target has an explicit structural failure and never reaches registry lookup.
- Check fingerprint after the allow-list so an attacker cannot retain =rlm_subagent= while replacing the query text or injecting extra command fields.
- Do not treat the compiler fingerprint as authority. Capabilities, authority, effects, approval, tool limits, cancellation and async scheduling remain in =rlm_tool=/registered handlers.
- Do not bypass =tool_invoke/7= with a direct subagent handler call.
- Do not add #175 deadline semantics in this slice.
- Do not duplicate the prompt/skill selection work owned by the compiler or the active #122 transaction.

* Decision
GO. The design closes a demonstrated missing generic-runtime seam by composing two already-canonical boundaries. It reduces host-language/manual glue while preserving the separation between symbolic command integrity and runtime execution authority.
